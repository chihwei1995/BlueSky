希望與威脅審核台 / Hope & Crisis Review Desk

具備協作管理功能的帳號，可在這裡審核其他氣候行動者提交的 Hope / Crisis 首頁候選資料，並更新狀態。

JSON 批次匯入 / JSON Batch Import

可上傳 JSON 檔，批次建立待審核的 Hope / Crisis 投稿。支援直接陣列，或包在 { "items": [...] } 的格式。

必要欄位：title、location、eventDate、summary。可選欄位：mode（hope / crisis）、credit、sourceUrl、media.downloadURL、media.type、media.name、media.path、coordinates.lat、coordinates.lng。

若有提供 media.downloadURL，審核台會直接顯示圖片或影片預覽；若 media.type 以 video/ 開頭，會用影片播放器呈現。
