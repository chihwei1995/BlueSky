Project Brief / 專案導覽

先看懂 Blue Sky Returns 想蒐集什麼、為什麼重要，再決定你要以哪一種方式參與這本國際環境電子書。

Crisis

Local climate impacts
地方氣候危機

整理 2024–2026 的極端高溫、暴雨、淹水、乾旱、海岸倒灌或其他在地氣候衝擊，用照片、短片與文字把「危機已經發生」說清楚。

Hope

Local green solutions
地方希望解方

拍下太陽能、風能、節能建築、社區綠電、韌性基礎建設或政策成果，讓不同國家都能看到「轉型正在發生」。

Participation Journey / 參與等級導覽

以下整理成更清楚的合作路徑。你提供的圖片概念，我把它轉成適合網站操作的三層導覽。

1
Level 1

Co-Promote / 共同推廣

先完成氣候行動問卷、建立帳號、理解 Blue Sky Returns 的方向，再協助分享給分會、學校與在地夥伴。

  • 完成問卷與角色卡
  • 分享專案連結與招募資訊
  • 引導更多夥伴加入
2
Level 2

Co-Create Local Data / 共創地方資料

Level 2 開始進入核心貢獻。你可以上傳地方希望與危機資料，提供電子書內容的第一手案例。

  • 上傳地方 Hope 與 Crisis
  • 可附短片、照片與簡短文字
  • 內容會進入待審核佇列
3
Level 3

Review & Educational Outreach / 審核與教育推廣

Level 3 具有審核權限，可檢視投稿品質、調整狀態，並為後續教材整理與教育應用把關。

  • 查看 `globeEventReviews` 待審資料
  • 將投稿標記為 Approved 或 Rejected
  • 協助電子書內容品質控管

Access Navigator / 權限導覽

這裡會根據你登入帳號的 `permissionLevel` 自動顯示能做的事。一般為 1，組織為 2，審核者為 3。

Level 1 / permissionLevel = 1

可閱讀介紹、理解資料規格、完成註冊與問卷，但不能直接提交地方希望 / 危機資料。

Level 2 / permissionLevel = 2

可前往上傳表單提交地方希望與危機內容，適合組織型氣候行動者、地方合作核心夥伴。

Level 3 / permissionLevel = 3

可上傳資料，也可在本頁審核 `globeEventReviews` 佇列，進行基本狀態管理。

Upload Flow / 上傳流程

目前上傳入口仍使用氣候行動者表單。你登入後若為 Level 2 或 3，系統會開放你進入上傳入口。

尚未登入氣候行動者帳號。請先登入後查看你的權限與可執行任務。
登入查看權限 / Sign In 註冊氣候行動者 / Register 前往上傳資料 / Submit Local Data

Reviewer Desk / 審核台

只有 `permissionLevel = 3` 的帳號會看到待審資料並可改變狀態。這裡先提供基本審核：`pending`、`approved`、`rejected`。
